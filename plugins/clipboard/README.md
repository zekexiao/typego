# TypeGo Clipboard

TypeGo 内置剪贴板历史插件，记录复制的文字、图片和本地文件，输入 `clip`（别名 `cb`、`paste`）搜索，
回车把选中内容重新写回系统剪贴板并隐藏启动器。

- 元信息声明 `background`，宿主启动时会初始化插件以持续采集剪贴板；禁用插件或退出后停止监听。
- 历史索引保存在宿主分配的插件数据目录，图片以 PNG 存在 `images/` 下；缩略图（64px）存在可清理的插件缓存目录，结果列表用它作为图标。文字、文件条目使用绘制的 T / F 文字图标，图片缩略图缺失时用 I 占位。条目数量、单条文本与图片尺寸都有上限。
- 相同内容只保留一条，再次复制会置顶；复制回剪贴板不会产生重复记录。
- 设置页可调整历史条数、分别开关文字/图片/文件采集，并清空历史。

使用仓库根目录的 `build.bat` 构建，安装包会把插件包放到 `plugins/clipboard` 下。
界面与剪贴板交互不在自动化测试覆盖范围内，需要本机验证。
