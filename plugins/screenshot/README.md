# TypeGo Screenshot

TypeGo 内置截图插件，对标 PixPin 的核心功能：按 `F1` 直接进入区域选择，支持标注、
复制、保存、贴图和历史记录。

## 入口

| 命令 | 说明 |
| --- | --- |
| `shot`（别名 `screenshot`、`snip`、`jietu`） | 区域截图，按 `F1` 等价 |
| `shot-full`（别名 `shot-screen`） | 从当前屏幕的整屏选区开始 |
| `shot-scroll`（别名 `shot-long`、`scrollshot`） | 框选后自动进入滚动长截图 |
| `shot-history`（别名 `shots`） | 浏览历史截图，回车贴到桌面 |

快捷键在「设置 > 插件」中可改；未设置过时截图默认使用 `F1`。

## 操作

- 拖拽框选；单击高亮的窗口可直接选中该窗口；回车复制，`Esc` 取消。
- 选区出现后工具栏提供：矩形、椭圆、箭头、直线、画笔、文字、高亮、马赛克、模糊、
  序号、颜色、粗细、撤销/重做、复制、另存、贴图、关闭。
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做，`Ctrl+S` 另存，`Ctrl+P` 贴图，`Ctrl+A` 全屏选区，
  方向键微调选区（Shift 加速）。
- `M` 马赛克、`B` 模糊、`T` 文字、`N` 序号、`R` 矩形、`O` 椭圆、`A` 箭头、
  `L` 直线、`P` 画笔、`H` 高亮、`V` 选择。
- 切回选择工具（`V`）后可以直接改已画的标注：单击矩形、箭头、文字等选中（蓝色虚线框），
  拖动移动；矩形/椭圆/高亮/马赛克/模糊拖四角手柄缩放，直线/箭头拖两端改端点；
  `Delete` 删除选中标注，`Esc` 取消选中。撤销/重做包含这些修改。
- 贴图窗口可拖动、滚轮或拖角缩放；贴图上方（上方放不下时在下方）常驻一条操作条：
  编辑标注、复制、另存、置顶、关闭。
- 双击贴图、点操作条「编辑」或按 `Ctrl+E` 重新进入标注编辑；`Esc`/`Delete` 删除贴图，
  `Ctrl+0` 恢复原始大小。
- 标注编辑窗口默认是「选择」工具：单击已有矩形、箭头、文字等即可选中（蓝色虚线框），
  拖动可移动位置；矩形/椭圆/高亮/马赛克/模糊拖四角手柄缩放，直线/箭头拖两端手柄改变
  端点；`Delete` 删除选中标注；双击文字标注可直接改字，清空内容即删除。
  颜色和粗细会应用到当前选中的标注，撤销/重做包含移动、缩放、改字和删除。
- 放大镜显示像素颜色、坐标和当前选区尺寸，可在设置中关闭或调整倍数。

## 滚动长截图

- 普通截图选区出来后点击工具栏的长截图按钮，或按 `S`；也可以直接用 `shot-scroll`，框选完成会自动开始。
- 选区必须位于同一块屏幕内。开始后选区外侧显示蓝色边框和右下角控制条，在选区内滚动鼠标滚轮即可。
- 自动识别向上/向下、向左/向右滚动，并尽量排除固定标题栏和页脚；完成后点「完成」查看长图，可复制或另存。
- 如果滚动过快导致相邻帧没有重叠，控制条会提示；稍微回滚再继续即可。拼接上限约 2400 万像素。

## 实现要点

- 使用 Win32 `BitBlt` 一次捕获虚拟桌面，再按 `EnumDisplayMonitors` 返回的物理矩形
  切分到各屏幕，避免混合 DPI 下 Qt 逻辑坐标和物理像素错位。
- 每个屏幕一个全屏覆盖层，选区使用全局逻辑坐标共享；截图时先隐藏 TypeGo 自身的
  顶层窗口（启动器、悬浮图标、贴图），完成或取消后恢复。
- 标注以矢量形式保存，复制/保存时才按选区起始屏幕的 DPI 合成，撤销不需要重存位图。
- 原图保存在插件数据目录 `history/`，缩略图保存在可清理的插件缓存目录。

## 与 PixPin 的差距

GIF 录制、OCR、屏幕录制尚未实现；这些能力需要额外的编码和 OCR 依赖，后续可独立加入。
滚动长截图要求选区在同一屏幕内，暂不支持跨屏拼接。
